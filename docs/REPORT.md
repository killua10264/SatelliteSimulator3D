## 3. Những gì đã thực hiện

### 3.1 Nền tảng dữ liệu (Thành viên A)

- **Thiết kế schema SQL**: bảng `planets` (id, name, radius_km, mass_kg, texture_file) và `satellites` (id, planet_id, name, latitude, longitude, altitude_km, is_relay) với khóa ngoại.
- **Seed data**: Script `seed_satellites.sql` idempotent (dùng `NOT EXISTS`) — 7 vệ tinh cho Earth (ISS, RELAY-A đến E, SAT-LEO), 3 cho Mars. An toàn chạy nhiều lần.
- **Model classes**: `Planet.java`, `Satellite.java` với đầy đủ getter/setter. `Satellite` lưu thêm tọa độ 3D runtime (x, y, z) dùng cho LOS.
- **DAO layer**: `PlanetDAO.findAll()`, `findById()`; `SatelliteDAO.findByPlanet()`, `insert()`, `delete()`, `deleteAutoGenerated()` — sử dụng PreparedStatement chống SQL Injection. Tất cả lỗi SQL đều ném `RuntimeException` rõ ràng thay vì nuốt lỗi.
- **CoordConverter**: Chuyển đổi (lat°, lon°, altKm) → (x, y, z) theo công thức hình cầu:
  - `r = (R_planet + alt) × SCALE`
  - `x = r·cos(lat)·cos(lon)`, `y = r·sin(lat)`, `z = r·cos(lat)·sin(lon)`

### 3.2 Physics Engine (Thành viên B)

**`PhysicsEngine.java`** — Tất cả công thức cơ học quỹ đạo:

| Công thức | Biểu thức | Ý nghĩa |
|---|---|---|
| Vận tốc quỹ đạo | `v = √(GM/r)` | Vận tốc tối thiểu để không rơi |
| Tần số góc | `ω = v/r` | rad/giây, dùng để animate |
| Chu kỳ quỹ đạo | `T = 2π/ω` | Thời gian một vòng |

Kiểm chứng với giá trị thực tế NASA:

| Vệ tinh | Độ cao | v tính được | v thực tế |
|---|---|---|---|
| ISS | 408 km | 7.67 km/s | ~7.66 km/s |
| GPS | 20180 km | 3.87 km/s | ~3.87 km/s |
| Địa tĩnh | 35786 km | 3.07 km/s | ~3.07 km/s |
| Hubble | 540 km | 7.59 km/s | ~7.59 km/s |

**`OrbitalSatellite.java`** — Cập nhật vị trí theo thời gian:
- Khởi tạo `θ₀` từ kinh độ ban đầu của vệ tinh.
- Mỗi frame: `θ += ω × dt × TIME_SCALE`
- Vệ tinh chuyển động trên mặt phẳng nghiêng theo vĩ độ ban đầu, giữ nguyên Y = r·sin(lat), quay trong mặt phẳng XZ.

### 3.3 JavaFX 3D UI (Thành viên B)

**Giao diện gồm 3 vùng:**

**Trái (SubScene — full screen)** — Không gian 3D:
- Cửa sổ tự động mở full screen (`stage.setMaximized(true)`). SubScene bind kích thước động vào container.
- Nền màu `#02030a` (màu vũ trụ).
- `PerspectiveCamera` đặt tại z = -900 (hoặc xa hơn với hành tinh lớn).
- Ánh sáng: `AmbientLight` (70,70,80) + `PointLight` trắng mô phỏng mặt trời.
- Hành tinh là `Sphere` với `PhongMaterial` có diffuse map từ texture file.
- Vệ tinh là `Sphere` nhỏ: relay (liên lạc) màu **vàng** 📡, thường màu **cyan** 🛰.
- Tương tác: kéo chuột để xoay, lăn chuột để zoom.

**Phải (Control Panel — ScrollPane)** — Bảng điều khiển cuộn được:
- Sidebar được bọc trong `ScrollPane` — có thể cuộn dọc khi nội dung vượt chiều cao màn hình.
- **ComboBox hành tinh**: chọn Earth / Mars.
- **Animation**: nút ⏸ Pause / ▶ Play + Slider TIME_SCALE (1× → 50000×).
- **Danh sách vệ tinh**: ListView màu chữ đen, icon emoji, hiển thị số lượng (`N vệ tinh`). Nút 🔄 làm mới danh sách.
- **Xóa vệ tinh**: nút 🗑 xóa vệ tinh đã chọn.
- **Thêm vệ tinh thủ công**: form Tên / Lat / Lon / Alt / checkbox Is Relay + nút ➕.
- **Sinh vệ tinh tự động**: ô nhập số N + checkbox Relay + nút ⚡ Sinh tự động.
- **Định tuyến**: ComboBox Từ / Đến + nút 🔍 Tìm đường + nút ❌ Xóa đường + nhãn kết quả.

**Dưới (Status Bar)** — Hiển thị hành tinh đang chọn và số vệ tinh.

### 3.4 Định tuyến & Benchmark (Thành viên C)

- **Line-of-Sight (`LineOfSight.java`)**: Kiểm tra hình học 3D — tìm điểm trên đoạn P1P2 gần tâm hành tinh nhất. LOS tồn tại khi khoảng cách đó > R_hành tinh. Không có điểm mù: kiểm tra đúng cho mọi góc quỹ đạo.
- **Định tuyến Dijkstra (`RoutingEngine.java`)**: Tìm đường ngắn nhất qua các vệ tinh relay có LOS với nhau. Xây đồ thị O(N²) rồi Dijkstra O(N log N). Vệ tinh nguồn/đích không cần là relay.
- **Laser beam 3D**: Mỗi đoạn đường dùng `Cylinder` + `Rotate` JavaFX — xanh lục nếu LOS OK, đỏ nếu bị che khuất.
- **Kiểm tra LOS theo frame**: `AnimationTimer` kiểm tra LOS từng đoạn mỗi frame. Khi phát hiện đoạn bị chặn, kích hoạt tự động định tuyến lại.
- **Auto-reroute**: Khi đường hiện tại bị ngắt, `tryReroute()` chạy Dijkstra lại ngay lập tức. Nếu tìm được đường mới, hiển thị `↺ Tự động định tuyến lại`. Nếu không, gọi `routeDiagnostics()` để báo nguyên nhân cụ thể.
- **Diagnostics**: Đếm số relay nhìn thấy được từ nguồn và đích — thông báo gợi ý "Thêm relay gần [nguồn/đích]" hoặc "Không có relay nào có LOS" thay vì thông báo chung chung.
- **Độ phức tạp**: O(N²) xây đồ thị + O(N log N) Dijkstra. Thực nghiệm cho thấy < 10ms với 50 node (xem `benchmark_report.txt`).
- **Kiểm chứng**: Chạy `BenchmarkRunner.java` độc lập để tái lập kết quả — seed ngẫu nhiên cố định (`seed=42`) đảm bảo output giống nhau trên mọi máy.

## 5. Hướng dẫn cài đặt chi tiết

### Bước 1 — Cài Java 17 (Eclipse Temurin)

Tải tại: https://adoptium.net/temurin/releases/?version=17

Sau khi cài, mở PowerShell và kiểm tra:
```powershell
java -version
# Kết quả mong đợi: openjdk version "17.x.x" ... Temurin
```

Nếu cần đặt thủ công (thêm vào PowerShell profile):
```powershell
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-17.x.x-hotspot"
$env:PATH      = "$env:JAVA_HOME\bin;$env:PATH"
```

### Bước 2 — Cài Apache Maven

Tải tại: https://maven.apache.org/download.cgi (chọn `apache-maven-3.9.x-bin.zip`)

Giải nén vào `C:\maven`, rồi thêm vào PATH:
```powershell
$env:PATH = "C:\maven\bin;$env:PATH"
mvn -v
# Kết quả mong đợi: Apache Maven 3.9.x
```

### Bước 3 — Cài SQL Server 2022 Express

Tải tại: https://www.microsoft.com/en-us/sql-server/sql-server-downloads (chọn Express)

Trong lúc cài, chọn **Mixed Mode Authentication** và đặt mật khẩu SA.

### Bước 4 — Bật TCP/IP cho SQL Server

1. Mở **SQL Server Configuration Manager**.
2. Vào `SQL Server Network Configuration` → `Protocols for MSSQLSERVER`.
3. Nhấp đúp `TCP/IP` → chuyển sang **Enabled**.
4. Khởi động lại service: mở **Services** → tìm `SQL Server (MSSQLSERVER)` → Restart.

### Bước 5 — Bật Mixed Mode Authentication (nếu chưa)

Mở PowerShell **Administrator** và chạy:
```powershell
Set-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Microsoft SQL Server\MSSQL16.MSSQLSERVER\MSSQLServer" -Name "LoginMode" -Value 2
Restart-Service MSSQLSERVER
```

### Bước 6 — Tạo Database và User

Mở **SSMS**, kết nối tới `localhost`, chạy lần lượt 2 file SQL trong thư mục `sql/`:

| Thứ tự | File | Nội dung |
|---|---|---|
| 1 | `sql/create_tables.sql` | Tạo database `satellite_db`, các bảng, login `satellite_user` |
| 2 | `sql/seed_satellites.sql` | Chèn dữ liệu hành tinh và vệ tinh mẫu |

Trong SSMS: **File** → **Open** → chọn file → nhấn **Execute** (F5).

Hoặc dùng `sqlcmd`:
```powershell
sqlcmd -S localhost -U sa -P "<mật khẩu SA>" -i sql/create_tables.sql
sqlcmd -S localhost -U satellite_user -P "Satellite@2024" -d satellite_db -i sql/seed_satellites.sql
```

> File `sql/seed_routing_test.sql` là tùy chọn — dữ liệu vệ tinh dày đặc hơn để kiểm thử định tuyến.

## 7. Ghi chú kỹ thuật

- **JavaFX Y-axis**: Trục Y của JavaFX 3D hướng xuống. Code dùng `-s.getY()` khi đặt vị trí lên scene để vĩ độ Bắc hiển thị đúng hướng lên trên.
- **SCALE = 1.0/100.0**: 1 đơn vị scene = 100 km. Trái Đất bán kính ≈ 63.7 đơn vị scene.
- **TIME_SCALE**: Hệ số nhân thời gian. Với `1000`, ISS (chu kỳ ~93 phút thực) hoàn thành 1 vòng sau ~5.6 giây thực.
- **LOS formula**: Góc nhìn tối đa giữa 2 vệ tinh cùng quỹ đạo `α_max = 2·arccos(R / r_orbit)`. Ở 800 km: α_max ≈ 54.4°. Điều này giới hạn mật độ vệ tinh tối thiểu cần thiết để phủ kín.
- **Fibonacci sphere**: `sinLat = sinLimit·(1 - 2·(i+0.5)/n)`, `lon = (360·i / φ) mod 360` với φ = golden ratio. Giới hạn ±55° vĩ độ để tránh cực bị cô lập.
- **SQL Authentication**: Kết nối DB dùng SQL Server Authentication — yêu cầu Mixed Mode và login `satellite_user / Satellite@2024`.
- **deleteAutoGenerated**: `SatelliteDAO` có phương thức xóa tất cả vệ tinh có tên `LIKE 'AUTO-%'` để dọn dẹp trước mỗi lần sinh mới.
